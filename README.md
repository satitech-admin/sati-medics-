# Sati Medics

Sati Medics is a responsive healthcare app prototype for a regional medicine-delivery, doctor-consultation, diagnostics and family-health platform.

## Current front-end build

The GitHub Pages build now includes:

- Premium responsive landing experience from hero section through full footer
- Original Sati Medics logo and installable PWA branding
- Multi-city selector for Betul, Itarsi, Harda, Narmadapuram, Bhopal, Nagpur and Indore
- Medicine catalogue search, category filters, cart and preview checkout
- Prescription-aware medicine flow and prescription upload UI
- Doctor specialty discovery and consultation-booking flow
- Video / audio / chat consultation UI states
- Lab-test catalogue and home-collection request flow
- Health programs for diabetes, BP/heart care, senior care, women's care, child care and mental wellness
- Family profile, local reminder and health-record UX
- Orders, appointments and delivery-tracking screens
- Service-city rollout page
- About, Support, Privacy, Terms and Medical Disclaimer pages
- PWA manifest, service worker and offline shell caching
- Mobile bottom navigation + desktop navigation
- Fully responsive layout for phone, tablet and desktop

## Important production note

This repository is currently a functional **front-end product prototype**. Sample doctors, medicine prices, lab prices, ratings and order states are UI data only.

Before accepting real healthcare transactions, the production system should add secure authentication, backend APIs, database storage, licensed pharmacy inventory and prescription review, verified doctor onboarding, compliant telemedicine, certified diagnostics integrations, payment gateway, notifications, delivery/rider operations, security controls, consent and privacy workflows, audit logs, and legal/regulatory review.

Sati Medics is not an emergency response service. For emergencies in India, users should contact 112 or seek immediate appropriate local care.
