# Sati Medics

Responsive healthcare app prototype for medicine delivery, doctor consultations, diagnostics and family care.

## Included
- Same-day medicine ordering UX
- Medicine search/category filters
- Prescription upload workflow
- Cart + delivery checkout
- Order tracking timeline
- Doctor specialty discovery
- Consultation booking + video-room preview
- Lab test booking
- Multi-city selector (Betul, Bhopal, Indore, Nagpur, Itarsi, Harda, Narmadapuram)
- Family health profile UX
- PWA manifest + service worker
- Fully responsive mobile/desktop design

> Important: doctor profiles, medicine pricing and checkout are demo data. Production healthcare launch requires licensed pharmacy fulfilment, pharmacist prescription review, verified doctor onboarding, privacy/security controls, payment, telemedicine and diagnostics integrations, and legal/compliance review.

Built for Sati Medics.
